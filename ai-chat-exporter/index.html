AI Chat Exporter

Export ChatGPT and Claude conversations to clean documents, with code blocks, tables and lists intact.

Coming soon to the Chrome Web Store

What it does

  • Adds an Export button on chatgpt.com and claude.ai, plus a toolbar popup.
  • Markdown export: free and unlimited.
  • PDF export with a print-ready layout.
  • Word (.docx) export with shaded code blocks and real tables.
  • Export only selected messages.
  • Keeps code blocks with their language, tables, nested lists, headings and blockquotes. Math is exported as LaTeX text.

Private by design

Conversations are read from the page when you export and are processed in your browser. The extension has no server and no analytics. It only runs on chatgpt.com and claude.ai.

Limits

Only messages loaded on the page are exported, so very long chats may be partial. Images are exported as text placeholders.

Free

Markdown, PDF, DOCX and selective export are all free. If it saves you time, you can support development with an optional donation.

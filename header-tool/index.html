Header Tool

Modify request headers, modify response headers and redirect URLs in Chrome, with no tracking and no accounts.

Add to Chrome

What it does

  • Set or remove request headers (Authorization, X-Debug, User-Agent, custom headers).
  • Set or remove response headers (CORS, Cache-Control, CSP experiments).
  • Redirect URLs with a URL pattern or a regular expression with capture groups.
  • Limit each rule by URL and resource type (page, XHR/fetch, script, image, and more).
  • Group rules into profiles, switch between them, and pause everything with one switch. The toolbar badge shows how many rules are active.

Built for trust

  • Uses Chrome's declarativeNetRequest API: the browser applies your rules, and the extension does not read your pages or traffic.
  • Rules are stored on your device.
  • Site access is optional and requested only when you add a rule.
  • No analytics, telemetry, ads or remote code.

Free

Header Tool is free, with unlimited rules and profiles and JSON import and export. If it saves you time, you can support development with an optional donation.

Header Tool is an independent project and is not affiliated with any other header-modification extension.

Header Tool privacy policy

Effective date: 2026-09-29

Header Tool does not collect, sell or share your browsing data, and contains no analytics, telemetry or ads.

Data stored on your device

Stored in chrome.storage.local (not synced by the extension):

  • Your profiles and rules: names, URL filters, header names and values, redirect targets and resource types.
  • The pause switch and the active profile.

Header values you enter are applied to requests by Chrome itself using declarativeNetRequest. The extension does not read page content, requests, responses, cookies or browsing history.

Network requests

The extension makes no network requests. It is free and processes no payment data. The optional "Support development" link simply opens a page of this website in a new tab.

Permissions

The extension requests storage and declarativeNetRequestWithHostAccess. Site access is an optional permission requested when you add rules and is used only to apply your own rules.

Changes

If this policy changes, the effective date above will be updated.

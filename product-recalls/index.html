Product Recalls API

CPSC, NHTSA, USDA FSIS, EU Safety Gate, and UK FSA product recalls in one unified JSON schema.

Open in Apify Store

Who it's for

  • E-commerce and FBA sellers: screen your catalog against multi-source recalls in real time.
  • Retailers: monitor shelves across regions and agencies with a single API.
  • Insurers and compliance teams: track and report product liability risks.
  • AI agents: call through Apify's MCP server to answer recall questions with authoritative source links.

What it does

  • Aggregates recalls from 5 official sources: CPSC, NHTSA, USDA FSIS, EU Safety Gate, UK FSA.
  • Returns a unified JSON schema across all agencies and regions.
  • "Only new" mode with a Monitor ID: each scheduled run returns only recalls you have not received before.
  • Supports API calls via Apify CLI or HTTP, and MCP integration for AI agents.
  • Filterable by source, country, category, company, and date range.

Data and privacy

Data comes from official government agencies and sources: US CPSC, NHTSA, USDA FSIS, EU Safety Gate, and UK FSA. The actor sends your filters only to the respective agency APIs. In "only new" mode it stores already-delivered recall IDs in a key-value store in your own Apify account. No tracking or third-party services.

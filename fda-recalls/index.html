FDA Recalls Monitor

FDA food, drug and medical device recalls from the official openFDA enforcement API, as clean, normalized JSON.

Open in Apify Store

What it does

  • Searches food, drug and device recalls, one category or all.
  • Filters by keyword, recalling firm, class (I, II, III), status, state, country and date range.
  • "Only new" mode with a Monitor ID: each scheduled run returns only recalls you have not received before.
  • Handles large pulls with automatic pagination and date-window splitting.
  • Retries failed requests with backoff. An optional openFDA API key raises rate limits.

Use cases

  • Compliance: run weekly for Class I recalls and send new items to Slack or email through an Apify integration.
  • Supply chain: watch specific suppliers or keywords such as "undeclared peanut" or "listeria".
  • QA and regulatory affairs: pull device recalls for a date range into a spreadsheet.
  • AI agents: call the actor through Apify's MCP server to answer recall questions with an FDA source link.
  • Retail and marketplaces: screen a product catalog against recalls.

Data and privacy

Data comes from openFDA and reflects FDA's Enforcement Report, so it can lag real-world announcements. The actor sends your filters (and optional openFDA API key) only to api.fda.gov. In "only new" mode it stores already-delivered recall numbers in a key-value store in your own Apify account. No tracking or third-party services.
